一页纸的速查表：类名 + 一句话 + 关键方法。要看实现的语义（每个注入点在哪、什么时候不干预）， 去 去哪看真实实现 列出的文件。

依赖坐标与模块 ​

模块 / 模组 id坐标内容
fabric-api（聚合器）cn.enaium.fabricpvz:fabric-api:1.2.2不含代码；模组依赖这个坐标就拿五个模块，聚合 jar 把五个模块装在自己里面（jar-in-jar），所以安装时只有一个文件
api-base同上，随聚合器带出PvzFabricApi、ModQuery、事件总线（api.event）
api-events同上LawnEvents（游戏事件）、GameLifecycleEvents（生命周期）与两个桥
api-plant同上PlantType、PlantRegistry、PlantOverrides、ProjectileOverrides、BoardOverrides、CustomPlantEvents、PlantRules、PlantHooks
api-resource同上ModImages、ModImageSlot、GameArt、ModReanims、ResourceOverrides、ResourceDiagnostics
api-zombie同上ZombieType、ZombieRegistry、ZombieOverrides、CustomZombieEvents、ZombieHooks

API 是可选依赖：源码用到它时，模组自己在 Gradle 里声明 cn.enaium.fabricpvz:fabric-api:1.2.2 （编译用 compileOnly / testCompileOnly，运行时用 testImplementation / pvzRunClasspath 且 isTransitive = false），并在 fabric.mod.json 的 depends 里写模块 id（或 "fabric-api"）。 不用 API 的模组不需要声明任何坐标。工具链不提供 API，也不替你选它的版本。
