这份文档是什么 ​

这个站点只讲一件事：给 PvZ-Portable 写模组。PvZ-Portable 是《植物大战僵尸》GOTY 的 Java 桌面移植版（JDK 25 + Gradle + LWJGL/SDL3），它跑在真正的 Fabric Loader 上，所以模组就是 普通的 Fabric 模组：一份 fabric.mod.json、一个 ModInitializer 入口点、一个 jar。

内容按"从零到能改游戏"的顺序组织：

章节读它是为了
1. 开始把环境和游戏准备好，让第一个空模组跑起来
2. 项目结构看懂一个模组工程的每个文件，以及工具链替你做了什么
3. 实验 Mixin不改游戏源码地改写游戏类，含完整可复制的例子
4. 植物与僵尸用 api-plant / api-zombie 注册内容与覆盖已有数值
5. 资源与美术图片、reanimation、散包覆盖 pak
6. 事件与生命周期用 api-events 观察游戏，以及什么时候不该用它
7. 实例精读pvz-content-mod 逐个文件读完：三株红植物是怎么长出来的
8. 构建、测试与发布把模组构建、测试、发布并交给玩家
9. API 速查需要查类名与方法时翻这一页

工作区里真实存在的东西 ​

文档里的每一段代码都来自工作区里的真实工程，可以照着读、照着跑：

工程是什么
PvZ-Portable/游戏本体（模组 id pvz-portable），不是模组
fabric-api/模组 API：api-base、api-events、api-plant、api-resource、api-zombie，聚合坐标 cn.enaium.fabricpvz:fabric-api
loom/工具链 Gradle 插件 cn.enaium.fabricpvz.loom：一行插件给你游戏本体与版本包清单里的库（Loader、Mixin、ASM、日志栈、LWJGL）、runClient 与 jar-in-jar
pvz-example-mod/最小可运行示例：事件 + 三个 mixin
pvz-content-mod/教学实例：三株红植物，注册 + 艺术管线 + 端到端测试
pvz-mod-95-edition/大型改版实例：以规则与数值覆盖为主的 Kotlin 模组

表中的每个工程都能直接打开对照；文档里的构建脚本与代码片段以它们的当前内容为准。 工具链只提供游戏本身与版本包清单里的库，Kotlin、JUnit、fabric-language-kotlin 与 API 都由每个模组自己声明。
